# House Prices Capstone

Wiki ini menerangkan langkah demi langkah apa yang diajar oleh Capstone Hari 53 dalam *100 Days of Code: The Complete Python Pro Bootcamp* di Udemy. Program ini mengambil senarai sewa (pautan, harga, alamat) dari klon Zillow dengan `requests` dan BeautifulSoup, dan mengisi borang Google dengan Selenium, sekali bagi setiap penyenaraian, supaya Google Sheet mengumpulkan satu baris bagi setiap hartanah.

Setiap halaman langkah menunjukkan tangkapan skrin langkah itu dan menyenaraikan apa yang kita peroleh. Kod berada dalam [repositori](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/053-capstone-house-prices); README menerangkan cara memasang, menjalankan dan menguji program.
