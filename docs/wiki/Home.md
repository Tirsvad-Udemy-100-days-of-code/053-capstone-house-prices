# House Prices Capstone

This wiki explains, step by step, what the Day 53 Capstone of Udemy's *100 Days of Code: The Complete Python Pro Bootcamp* taught. The program scrapes rental listings (link, price, address) from the Zillow clone with `requests` and BeautifulSoup, and fills a Google Form with Selenium, once per listing, so that a Google Sheet collects one row per property.

Each step page shows a screenshot of the step and lists what we gained from it. The code is in the [repository](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/053-capstone-house-prices); the README tells how to set it up, run it and test it.
