# House Prices Capstone

Denne wiki forklarer trin for trin, hvad Dag 53 Capstone i Udemys *100 Days of Code: The Complete Python Pro Bootcamp* lærte os. Programmet henter udlejningsannoncer (link, pris, adresse) fra Zillow-klonen med `requests` og BeautifulSoup og udfylder en Google-formular med Selenium, én gang pr. annonce, så et Google Sheet samler én række pr. bolig.

Hver trinside viser et skærmbillede af trinnet og beskriver, hvad vi fik ud af det. Koden ligger i [repositoriet](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/053-capstone-house-prices); README fortæller, hvordan man installerer, kører og tester den.
