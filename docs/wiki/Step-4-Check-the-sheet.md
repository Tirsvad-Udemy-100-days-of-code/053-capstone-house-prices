# Step 4: Check the Sheet

We opened the Google Sheet and checked that it holds one row per listing: 44 responses with address, price and link. The screenshot shows the first rows.

![Step 4: Check the Sheet](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/053-capstone-house-prices/raw/branch/main/docs/images/04-sheet-responses.png)

## What we gained

- Run the real thing once: the real form showed two problems (language and waiting) that a local mock form did not.
- Compare the row count of the Sheet with the number of listings.
- A response cannot be taken back by the program, so ask before the first real submit.
